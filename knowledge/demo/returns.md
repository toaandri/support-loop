# Politique de retour - boutique fictive SupportLoop

Ces conditions concernent uniquement la boutique fictive de demonstration.

Un client peut demander un retour dans les 14 jours suivant la livraison.
Le produit doit etre non utilise, complet et dans son emballage d'origine.
Pour commencer le retour, contacter le support avec le numero de commande.
Le remboursement est effectue sur le moyen de paiement initial apres reception
et verification du produit retourne.

Une commande deja expediee ne peut pas etre annulee. Le client doit attendre
la livraison puis demander un retour dans les 14 jours.
